# Mnemonic
Mnemo Minds™ è un’applicazione Android nativa in Java progettata per l’archiviazione geografica della memoria. Il sistema trasforma le coordinate GPS in contenitori semantici, permettendo di ancorare contenuti multimediali e riflessioni personali a luoghi fisici precisi, superando la dispersione dei dati tipica del cloud storage tradizionale.
----------------------------------------------------------------
L’architettura full-stack utilizza Firebase per la gestione di database NoSQL, autenticazione e storage, integrando Google Maps SDK per la componente cartografica. Lo sviluppo segue una logica offline-first con sincronizzazione asincrona e ottimizzazione dei consumi energetici tramite FusedLocationProvider, garantendo prestazioni elevate e continuità operativa.
------------------------------------------------------------------
Il fulcro funzionale è il "Memory Pin", un sistema stratificato per la raccolta di dati testuali, multimediali e metadati ambientali (meteo, timestamp). La privacy è centrale: l'applicazione è priva di pubblicità e metriche social, implementando la crittografia dei dati sensibili e una gestione della visibilità basata esclusivamente su gruppi privati e Deep Link univoci.
------------------------------------------------------------------
